# 📊 London Airbnb Market Analysis

## 📌 Overview

This project presents interactive dashboards built using **Tableau** and **Power BI** to analyse the London Airbnb market.

The aim is to uncover insights related to pricing, availability, and investment opportunities.

---

## 🔴 Live Dashboard

👉 **View Interactive Dashboard (Tableau Public):**
https://public.tableau.com/app/profile/gaurav.jangra6746/viz/LondonAirbnbMarketAnalysis/InvestorDashboard?publish=yes

---

## 🧠 Objectives

* Analyse Airbnb pricing patterns across London
* Understand availability vs demand
* Identify profitable areas for investment

---

## 🛠️ Tools Used

* Tableau (.twbx)
* Power BI (.pbix)

---

## 📂 Project Structure

* 📁 `tableau/` → Tableau dashboard file
* 📁 `powerbi/` → Power BI dashboard file
* 📁 `images/` → Screenshots of dashboards

## 📊 Key Insights

* Central London areas show higher prices but lower availability
* Outer boroughs provide better long-term investment opportunities
* Demand and availability show strong geographical patterns
