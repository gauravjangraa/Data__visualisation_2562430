# 📊 Data Visualisation Dashboard Project

## 📌 Overview

This project presents interactive dashboards built using **Tableau** and **Power BI** to analyse Airbnb data.

The goal is to explore patterns, trends, and insights using effective data visualisation techniques.

---

## 🧠 Objectives

* Analyse pricing, availability, and demand
* Identify geographical trends
* Support decision-making through visual insights

---

## 🛠️ Tools Used

* Tableau (.twbx)
* Power BI (.pbix)

---

## 📂 Project Files

* 📁 `tableau/` → Tableau dashboard
* 📁 `powerbi/` → Power BI dashboard
* 📁 `images/` → Dashboard screenshots

---

## 📸 Dashboard Preview

---

## 📊 Key Insights

* High demand areas show higher pricing
* Availability varies by location and season
* Certain regions offer better investment opportunities

---

## 🎯 Learning Outcomes

This project demonstrates:

* Data visualisation design principles
* Use of interactive dashboards
* Storytelling using data

---

## 📎 How to Use

1. Download the `.twbx` file → Open in Tableau
2. Download the `.pbix` file → Open in Power BI
